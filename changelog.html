Release notes

To update, open Online Store › Themes and follow the update notice on your Sienna Beauty theme.

Version 1.0.0

First release candidate for the Shopify Theme Store.

  • Design: new Porcelain, Blush, Rose, Eucalyptus and Sage palette (every pair checked for WCAG AA contrast). Soft rounded image frames by default; the hero keeps its arch through a new slideshow "Image shape" setting. Paper texture is off by default.
  • Stories: the row fills the page width on desktop with larger bubbles.
  • Fixes:
    • The page no longer stops scrolling when Shopify adds its own dialogs, such as Shop sign-in. Scroll lock now applies only to the theme's modal drawers.
    • The search modal closes on Escape.
    • Jumping down a page (anchor links, scroll restore) no longer leaves sections invisible.
    • No layout shift on the mobile collection page (CLS 0.25 → 0).
    • The desktop dropdown and mega menu stay open while the pointer moves from the link down to the panel (hover bridge plus a short close delay).
    • No sideways scrolling on iPhone Safari. Screen-reader text inside swipe rows no longer widens the page.
    • Cart note autosave and the back/forward cart refresh no longer throw when offline.
    • No white gap above the announcement bar (skip link).
    • Cart count updates straight away.
    • Mobile header and footer layout fixed.
  • Demo content: Sienna Beauty preset with logo, favicon, 16 products, 14 collections, journal articles and an About page.

Version 0.1.0

First development build.

  • Foundation: settings, five color schemes, typography (Fraunces and Figtree), arch image frames, right-to-left support.
  • Header with mega menu, predictive search, country and language selectors, account component. Announcement bar. Footer with newsletter, payment icons and Follow on Shop. Mobile bottom navigation.
  • Product page built from blocks, with variant picker and swatches, media gallery (video, 3D/AR, zoom), subscriptions, gift card recipients, pickup availability, Shop Pay Installments, complementary and related products, and sticky add to cart.
  • Collection and search pages with filtering, sorting and pagination. Cart drawer and cart page with discounts, notes and subscriptions. Quick add.
  • Blog, article with comments, page, contact, 404, password and gift card templates.
  • Home and editorial sections: slideshow, stories, collection list, featured collection, collection tabs, image with text, routine builder, before/after, ingredients, video, video reviews, icons with text, testimonials, sale countdown, campaign banner, shop the look, blog posts, email signup, logo list, FAQ, featured product, image banner, rich text, custom Liquid, apps.
  • Removed dark mode.
  • Audit fixes against the Theme Store requirements and theme docs:
    • Accessibility: contrast-safe muted text and input borders, 44px touch targets, filter drawer as a native dialog, valid predictive search listbox, pause buttons for every auto-rotating element, focus moves to form messages.
    • Product page: gallery previous/next buttons, quick add rendered in its own section, SKU and vendor blocks, subscription group names and per-delivery prices, plan kept when the variant changes, gift card recipient rules.
    • Cart: unit price each, subtotal → discounts → estimated total, Shop Pay Installments, pre-order "due today", app blocks.
    • Performance: one high-priority image per page, critical CSS in the head, per-section scripts, reveal animation only below the fold.
    • Theme editor: selected blocks stay visible, inspector support, listener cleanup, content sections kept out of header and footer groups, `"tag": null` on theme blocks.
    • Safety: escaped search terms and line-item properties, neutral default copy (no claims a store may not be able to make).
