Collections and search

Collection and search result pages share the same product grid, filters and sorting. Open them in the theme editor from the top dropdown (Collections › Default collection or Search).

Collection page settings

SettingWhat it does
Show collection description / imageShows the description and image you set in Products › Collections in the banner.
Products per pageHow many products load before pagination.
Products per row on desktop / mobileGrid density. Mobile can show one or two products per row.
Enable filteringShows filters for availability, price, product type, vendor, tags, variant options and metafields.
Desktop filter layoutSidebar keeps filters next to the grid. Drawer opens them in a side panel. Mobile always uses the drawer.
Enable sortingFeatured, best selling, A–Z, price and date sorting.

Setting up filters

  1. Install the free Shopify Search & Discovery app.
  2. In the app, open Filters and add the filters you want, for example Skin type or Concern from a product metafield.
  3. Sienna shows them automatically. Color options with swatches show as swatch filters.

Shopify's filtering has some limits. For example, a collection with more than 5,000 products doesn't show filters. See Shopify Help: Filters.

Product cards

Product cards are set in Theme settings › Product cards. They control the style, image ratio, the second image on hover, vendor, rating and the Quick add button.

  • Color swatches and the Sale and Sold out badges appear automatically.
  • Quick add adds products with one variant straight to the cart. Products with options open a small picker first.

Collection list page

The /collections page lists all your collections. You can change its heading, the number of collections per row and the color scheme.

Search

  • Predictive search: while shoppers type, the search modal suggests products, collections, pages and articles. Turn this on or off in Theme settings › Search behavior, where you can also choose to show vendor and price.
  • Search results page: has the same filters, sorting and grid settings as collections.
  • Improve results: use Search & Discovery to add synonyms and boost products.
