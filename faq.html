Frequently asked questions

How do I install Camellia?

Go to Online Store › Themes in your admin, find Camellia in the Theme Store, and click Try theme or Buy theme. The theme is added to your theme library, where you can customize it before you publish. See Getting started.

Can I try Camellia before I buy it?

Yes. With Try theme you can customize the theme in your store for free. You only pay when you publish it.

How do I make my store look like the demo?

The Camellia preset includes the demo's layout and settings. To get the same look, add your own products and images, then pick collections in the homepage sections. Use photos with the same ratio as the demo, for example portrait 4:5 for products.

Will I lose my changes when I update the theme?

No. When a new version is out, the theme library shows an update. Shopify adds a new copy of the theme to your library with your settings and content kept. Code you edited yourself isn't carried over. Note any code changes before you update.

Why don't filters show on my collection page?

Check that Enable filtering is turned on in the collection section, and that filters are set up in the Search & Discovery app. Filters don't show on collections with more than 5,000 products. See Collections and search.

How do I add product reviews?

Install a reviews app that saves ratings to Shopify's standard product rating metafield (for example Judge.me or Shopify's Product Reviews). Turn on Show product rating in Theme settings › Product cards, then add the Product rating block to the product page. Reviews widgets are added as app blocks.

How do I show ingredients and how to use as tabs?

In the product description, add a Heading 2 or Heading 3 before each part, such as "Ingredients" or "How to use". Then turn on Split description into tabs in the Description block.

Does Camellia support subscriptions?

Yes. Install any subscriptions app and add a plan to a product. The plan choice shows on the product page automatically.

Does Camellia support right-to-left languages such as Arabic?

Yes. The layout flips automatically for Arabic, Hebrew, Persian and Urdu. See Languages and markets.

How do I change fonts and colors?

Use Theme settings › Typography and Theme settings › Colors. Changing a color scheme updates every section that uses it. See Theme settings.

How do I make a mega menu?

In Content › Menus, give a top-level item a second level (column headings) and a third level (links). Camellia shows that item as a full-width mega menu on desktop. Pick the menu in the Header section. See Header and footer.

My store is slow. Is it the theme?

Camellia loads images at the right size and lazy-loads them, and it uses very little JavaScript. Most slowdowns come from apps and very large images. Remove apps you don't use, and upload images no larger than 3000 px. Check speed in Online Store › Themes › View report.

Do you offer customization work?

Support covers using the theme's settings, bugs and questions about features. Custom code changes and third-party app problems aren't covered, but we're happy to point you in the right direction. See Support.
